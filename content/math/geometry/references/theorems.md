## Lines and angles

| Fact | Statement |
|---|---|
| Segment / Angle Addition | $AB + BC = AC$; $m\angle ABD + m\angle DBC = m\angle ABC$ |
| Midpoint, bisector | whole $= 2 \times$ half |
| Complementary / supplementary | sum $90^\circ$ / sum $180^\circ$ |
| Linear pair | supplementary |
| Vertical angles | congruent |
| Angles around a point | sum $360^\circ$ |

## Logic

| Statement | Form |
|---|---|
| Conditional | $p \to q$ |
| Converse / inverse / contrapositive | $q \to p$ / $\sim p \to \sim q$ / $\sim q \to \sim p$ |
| Equivalent pairs | conditional ⟺ contrapositive; converse ⟺ inverse |
| Detachment | $p \to q$ and $p$ ⇒ $q$ |
| Syllogism | $p \to q$ and $q \to r$ ⇒ $p \to r$ |

## Parallel lines cut by a transversal

| Pair | Relationship |
|---|---|
| Corresponding | congruent |
| Alternate interior | congruent |
| Alternate exterior | congruent |
| Consecutive (same-side) interior | supplementary |

Each converse proves lines parallel. Playfair: exactly one parallel through an outside point.

## Triangles

| Fact | Statement |
|---|---|
| Angle sum | $180^\circ$ |
| Exterior angle | $=$ sum of the two remote interior angles |
| Congruence tests | SSS, SAS, ASA, AAS, HL (not SSA, AAA) |
| CPCTC | corresponding parts of congruent triangles are congruent |
| Isosceles | angles opposite congruent sides are congruent (and conversely) |
| Triangle inequality | $\lvert a - b\rvert < c < a + b$ |
| Side–angle | longest side opposite largest angle |
| Hinge | larger included angle ⟺ longer third side |
| Midsegment | parallel to third side, half as long |
| Similarity tests | AA, SSS~, SAS~ |
| Side Splitter | $\tfrac{AD}{DB} = \tfrac{AE}{EC}$ when $\overline{DE} \parallel \overline{BC}$ |
| Angle Bisector | $\tfrac{BD}{DC} = \tfrac{AB}{AC}$ |

## Centers of a triangle

| Center | Lines | Property |
|---|---|---|
| Circumcenter | perpendicular bisectors | equidistant from vertices |
| Incenter | angle bisectors | equidistant from sides; $r = K/s$ |
| Centroid | medians | $\tfrac23$ from vertex; average of vertices |
| Orthocenter | altitudes | — |

## Right triangles

| Fact | Statement |
|---|---|
| Pythagorean theorem | $a^2 + b^2 = c^2$ |
| Classify by sides | $c^2 =, <, > a^2 + b^2$: right, acute, obtuse |
| 45°-45°-90° | $1 : 1 : \sqrt2$ |
| 30°-60°-90° | $1 : \sqrt3 : 2$ |
| Altitude to hypotenuse | $h = \sqrt{xy}$; leg $= \sqrt{c \cdot \text{adjacent piece}}$ |

## Any triangle (oblique triangles)

Side $a$ is opposite $\angle A$, $b$ opposite $\angle B$, $c$ opposite $\angle C$.

| Fact | Statement |
|---|---|
| Obtuse angles | $\sin\theta = \sin(180^\circ - \theta)$, $\cos\theta = -\cos(180^\circ - \theta)$ |
| Law of Sines | $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$ (use for AAS, ASA, SSA) |
| Law of Cosines | $a^2 = b^2 + c^2 - 2bc\cos A$ (use for SAS, SSS) |
| Angle from three sides | $\cos A = \dfrac{b^2 + c^2 - a^2}{2bc}$ |
| SSA, acute $A$, $h = b\sin A$ | $a < h$: none; $a = h$: one right triangle; $h < a < b$: two; $a \ge b$: one |
| SSA, right or obtuse $A$ | one triangle if $a > b$, none otherwise |
| Safe order | find the largest angle with the Law of Cosines (or last, by subtraction) |

## Polygons and quadrilaterals

| Fact | Statement |
|---|---|
| Interior angle sum | $(n - 2) \cdot 180^\circ$ |
| Exterior angle sum | $360^\circ$ |
| Regular $n$-gon angle | exterior $\tfrac{360^\circ}{n}$, interior $180^\circ - \tfrac{360^\circ}{n}$ |
| Diagonals | $\tfrac{n(n-3)}{2}$ |
| Parallelogram | opposite sides/angles congruent; consecutive angles supplementary; diagonals bisect each other |
| Rectangle | congruent diagonals |
| Rhombus | perpendicular diagonals that bisect the angles |
| Trapezoid midsegment | $\tfrac{b_1 + b_2}{2}$ |
| Kite | perpendicular diagonals; one pair of opposite angles congruent |

## Circles

| Fact | Statement |
|---|---|
| Central angle | $=$ arc |
| Inscribed angle | $\tfrac12$ arc; semicircle ⇒ right angle |
| Cyclic quadrilateral | opposite angles supplementary |
| Tangent | perpendicular to radius; two tangents from a point are congruent |
| Chord ⟂ radius | bisects the chord |
| Angle, vertex inside | $\tfrac12$(sum of arcs) |
| Angle, vertex outside | $\tfrac12$(far arc − near arc) |
| Chords | $AE \cdot EB = CE \cdot ED$ |
| Secants | outside · whole $=$ outside · whole |
| Tangent and secant | tangent² $=$ outside · whole |

## Other geometries

| Geometry | Parallels through an outside point | Triangle angle sum |
|---|---|---|
| Euclidean | 1 | $180^\circ$ |
| Hyperbolic | infinitely many | $< 180^\circ$ |
| Elliptic (spherical) | 0 | $> 180^\circ$; area $= R^2E$ |
