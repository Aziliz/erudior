## Oscillations

| | |
|---|---|
| SHM | $x = A\cos(\omega t + \phi)$; $a = -\omega^2x$ |
| Spring | $\omega = \sqrt{k/m}$, $T = 2\pi\sqrt{m/k}$ |
| Simple pendulum | $T = 2\pi\sqrt{L/g}$ |
| Physical pendulum | $T = 2\pi\sqrt{I/(mgd)}$ |
| Maxima | $v_{\max} = A\omega$, $a_{\max} = A\omega^2$; $E = \tfrac12kA^2$ |

## Waves and sound

| | |
|---|---|
| Wave speed | $v = f\lambda$; string: $v = \sqrt{F_T/\mu}$ |
| Traveling wave | $y = A\sin(kx - \omega t)$, $k = 2\pi/\lambda$, $\omega = 2\pi f$ |
| String fixed at both ends; open pipe | $f_n = \dfrac{nv}{2L}$, $n = 1, 2, 3, \ldots$ |
| Pipe closed at one end | $f_n = \dfrac{nv}{4L}$, $n = 1, 3, 5, \ldots$ |
| Intensity | $I = \dfrac{P}{4\pi r^2}$; $\beta = 10\log_{10}\dfrac{I}{I_0}$, $I_0 = 10^{-12}$ W/m² |
| Beats | $f_{\text{beat}} = \lvert f_1 - f_2\rvert$ |
| Doppler | $f' = f\dfrac{v \pm v_o}{v \mp v_s}$ (upper signs: approaching) |

## Fluids

| | |
|---|---|
| Density, pressure | $\rho = m/V$, $P = F/A$ |
| Depth | $P = P_0 + \rho gh$ |
| Pascal | $F_1/A_1 = F_2/A_2$ |
| Buoyancy | $F_B = \rho_{\text{fluid}}V_{\text{disp}}g$ |
| Continuity | $A_1v_1 = A_2v_2$ |
| Bernoulli | $P + \tfrac12\rho v^2 + \rho gy$ = const |
| Torricelli | $v = \sqrt{2gh}$ |

## Heat and gases

| | |
|---|---|
| Expansion | $\Delta L = \alpha L\Delta T$ |
| Heat | $Q = mc\Delta T$; phase change $Q = mL$ |
| Conduction, radiation | $Q/t = kA\Delta T/L$; $P = e\sigma AT^4$ |
| Ideal gas | $PV = nRT = Nk_BT$ |
| Kinetic theory | $\tfrac12m\overline{v^2} = \tfrac32k_BT$; $v_{\text{rms}} = \sqrt{3RT/M}$ |
| Monatomic gas | $E_{\text{int}} = \tfrac32nRT$; $C_V = \tfrac32R$, $C_P = \tfrac52R$, $\gamma = \tfrac53$ |

## Thermodynamics

| | |
|---|---|
| First law | $\Delta E_{\text{int}} = Q - W$ ($W$ by the gas); AP Physics 2 form: $\Delta U = Q + W$ with $W = -P\Delta V$ done *on* the gas |
| Work by gas | area under the $PV$ curve; isobaric $P\Delta V$; isothermal $nRT\ln(V_f/V_i)$ |
| Adiabatic | $PV^\gamma$ = const, $TV^{\gamma - 1}$ = const |
| Engine | $e = \dfrac{W}{Q_H} = 1 - \dfrac{Q_C}{Q_H}$; Carnot $e = 1 - \dfrac{T_C}{T_H}$ |
| Refrigerator | $K = Q_C/W$; Carnot $\dfrac{T_C}{T_H - T_C}$ |
| Entropy | $\Delta S = Q/T$ for heat $Q$ transferred at constant $T$ (e.g. melting, boiling, a large reservoir); Carnot engine $Q_H/T_H = Q_C/T_C$ |
