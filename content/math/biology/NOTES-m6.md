## Design decisions to review
- Drill answers must be numbers, so the sequence drills (bio-complement, bio-transcribe, bio-translate) are numbered multiple choice: each holds a pool of 12 pre-generated problems (fixed sequences with distractors built from real mistakes: copying, using U in DNA, reversed order, anticodon lookup, frame shift, starting at base 1). The learner types the option number. bio-mutation-effect (16 problems) asks for a code: 1 silent, 2 missense, 3 nonsense, 4 frameshift. Mechanism: two `choices` vars (`prob`, `sol`) whose values match (10 × item + answer), tied by `where: prob == sol`; `ans = mod(prob, 10)`. Pools were generated by script and every key re-verified against the codon table; correct positions are balanced within each pool.
- Prompts in those drills tell learners to use "the codon table from the lesson". The editor may want to add the codon table to `bio-ref-genetics` so it opens beside drills.
