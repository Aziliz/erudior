## Electrostatics

| | |
|---|---|
| Coulomb's law | $F = k\dfrac{\lvert q_1q_2\rvert}{r^2}$ |
| Field | $\vec E = \vec F/q$; point charge $E = kq/r^2$ |
| Gauss's law | $\oint\vec E\cdot d\vec A = Q_{\text{enc}}/\varepsilon_0$ |
| Line, sheet | $E = \dfrac{2k\lambda}{r}$; $E = \dfrac{\sigma}{2\varepsilon_0}$ |
| Potential | $V = kq/r$; $U = kq_1q_2/r$; $\Delta U = q\Delta V$ |
| Field from potential | $\Delta V = -\int\vec E\cdot d\vec\ell$; $\vec E = -\nabla V$; uniform: $E = \Delta V/d$ |
| Capacitance | $C = Q/V$; parallel plates $C = \kappa\varepsilon_0A/d$ |
| Capacitor energy | $U = \tfrac12CV^2$; $u = \tfrac12\varepsilon_0E^2$ |
| Combinations | parallel $C = \sum C_i$; series $1/C = \sum 1/C_i$ |

## Circuits

| | |
|---|---|
| Current, Ohm's law | $I = dQ/dt$; $V = IR$; $R = \rho L/A$ |
| Power | $P = IV = I^2R = V^2/R$ |
| Resistors | series $R = \sum R_i$; parallel $1/R = \sum 1/R_i$ |
| Real battery | $V = \mathcal{E} - Ir$ |
| Kirchhoff | $\sum I_{\text{in}} = \sum I_{\text{out}}$; $\sum\Delta V = 0$ around a loop |
| RC | $\tau = RC$; charging $q = C\mathcal{E}(1 - e^{-t/\tau})$; discharging $q = Q_0e^{-t/\tau}$ |

## Magnetism and induction

| | |
|---|---|
| Force on charge | $F = \lvert q\rvert vB\sin\theta$; $\vec F = q\vec v\times\vec B$; $r = \dfrac{mv}{\lvert q\rvert B}$ |
| Force on wire | $F = ILB\sin\theta$; loop torque $\tau = NIAB\sin\phi$ |
| Straight wire | $B = \dfrac{\mu_0I}{2\pi r}$ |
| Loop center, solenoid | $B = \dfrac{\mu_0I}{2R}$; $B = \mu_0nI$ |
| Parallel wires | $F/L = \dfrac{\mu_0I_1I_2}{2\pi d}$ |
| Biot–Savart, Ampère | $d\vec B = \dfrac{\mu_0}{4\pi}\dfrac{I\,d\vec\ell\times\hat r}{r^2}$; $\oint\vec B\cdot d\vec\ell = \mu_0I_{\text{enc}}$ |
| Faraday | $\mathcal{E} = -N\dfrac{d\Phi_B}{dt}$, $\Phi_B = BA\cos\theta$; motional $\mathcal{E} = BLv$ |
| Transformer | $V_s/V_p = N_s/N_p$ |
| Inductance | $\mathcal{E} = -L\,dI/dt$; $U = \tfrac12LI^2$; RL $\tau = L/R$ |
| LC, AC | $f = \dfrac{1}{2\pi\sqrt{LC}}$; $V_{\text{rms}} = V_0/\sqrt2$; $X_C = \dfrac{1}{\omega C}$, $X_L = \omega L$; $Z = \sqrt{R^2 + (X_L - X_C)^2}$ |

## Light and optics

| | |
|---|---|
| EM waves | $c = f\lambda = 1/\sqrt{\mu_0\varepsilon_0}$; $E = cB$ |
| Polarization | $I = I_0\cos^2\theta$ |
| Refraction | $n = c/v$; $n_1\sin\theta_1 = n_2\sin\theta_2$; $\sin\theta_c = n_2/n_1$ |
| Mirrors and lenses | $\dfrac1{d_o} + \dfrac1{d_i} = \dfrac1f$; $m = -\dfrac{d_i}{d_o}$; mirror $f = R/2$; $P = 1/f$ |
| Double slit, grating | $d\sin\theta = m\lambda$ (bright); $\Delta y = \lambda L/d$ |
| Single slit | $a\sin\theta = m\lambda$ (dark) |
| Resolution | $\theta_{\min} = 1.22\lambda/D$ |
| Thin film (one flip) | bright: $2nt = (m + \tfrac12)\lambda$ |

## Modern physics

| | |
|---|---|
| Relativity | $\gamma = \dfrac{1}{\sqrt{1 - v^2/c^2}}$; $\Delta t = \gamma\Delta t_0$; $L = L_0/\gamma$ |
| Velocity addition | $u = \dfrac{u' + v}{1 + u'v/c^2}$ |
| Energy, momentum | $E = \gamma mc^2$, $K = (\gamma - 1)mc^2$, $p = \gamma mv$, $E^2 = (pc)^2 + (mc^2)^2$ |
| Photons | $E = hf = hc/\lambda$; $p = h/\lambda$ |
| Photoelectric effect | $K_{\max} = hf - \phi$ |
| Hydrogen | $E_n = -\dfrac{13.6\text{ eV}}{n^2}$ |
| Matter waves | $\lambda = h/p$; $\Delta x\,\Delta p \ge h/4\pi$ |
| Binding energy | $E_B = \Delta m\,c^2$ (1 u ↔ 931.5 MeV) |
| Decay | $N = N_0e^{-\lambda t} = N_0(\tfrac12)^{t/T_{1/2}}$; $T_{1/2} = \ln 2/\lambda$; $R = \lambda N$ |
