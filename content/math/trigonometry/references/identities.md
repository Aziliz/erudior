## Fundamental identities

| Type | Identities |
|---|---|
| Reciprocal | $\csc x = \dfrac{1}{\sin x}$, $\sec x = \dfrac{1}{\cos x}$, $\cot x = \dfrac{1}{\tan x}$ |
| Quotient | $\tan x = \dfrac{\sin x}{\cos x}$, $\cot x = \dfrac{\cos x}{\sin x}$ |
| Pythagorean | $\sin^2 x + \cos^2 x = 1$, $1 + \tan^2 x = \sec^2 x$, $1 + \cot^2 x = \csc^2 x$ |
| Even–odd | $\sin(-x) = -\sin x$, $\cos(-x) = \cos x$, $\tan(-x) = -\tan x$ |
| Cofunction | $\sin\left(\tfrac{\pi}{2} - x\right) = \cos x$, $\tan\left(\tfrac{\pi}{2} - x\right) = \cot x$, $\sec\left(\tfrac{\pi}{2} - x\right) = \csc x$ |
| Periodicity | $\sin(x + 2\pi) = \sin x$, $\cos(x + 2\pi) = \cos x$, $\tan(x + \pi) = \tan x$ |

## Sum and difference

| Formula | |
|---|---|
| $\sin(\alpha \pm \beta)$ | $\sin\alpha\cos\beta \pm \cos\alpha\sin\beta$ |
| $\cos(\alpha \pm \beta)$ | $\cos\alpha\cos\beta \mp \sin\alpha\sin\beta$ |
| $\tan(\alpha \pm \beta)$ | $\dfrac{\tan\alpha \pm \tan\beta}{1 \mp \tan\alpha\tan\beta}$ |
| $a\sin x + b\cos x$ | $R\sin(x + \varphi)$, $R = \sqrt{a^2 + b^2}$, $\cos\varphi = \tfrac{a}{R}$, $\sin\varphi = \tfrac{b}{R}$ |

## Double angle and power reducing

| Formula | |
|---|---|
| $\sin 2x$ | $2\sin x\cos x$ |
| $\cos 2x$ | $\cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$ |
| $\tan 2x$ | $\dfrac{2\tan x}{1 - \tan^2 x}$ |
| $\sin^2 x$ | $\dfrac{1 - \cos 2x}{2}$ |
| $\cos^2 x$ | $\dfrac{1 + \cos 2x}{2}$ |
| $\tan^2 x$ | $\dfrac{1 - \cos 2x}{1 + \cos 2x}$ |

## Half angle

Sign of $\pm$: the quadrant of $\tfrac{\theta}{2}$.

| Formula | |
|---|---|
| $\sin\dfrac{\theta}{2}$ | $\pm\sqrt{\dfrac{1 - \cos\theta}{2}}$ |
| $\cos\dfrac{\theta}{2}$ | $\pm\sqrt{\dfrac{1 + \cos\theta}{2}}$ |
| $\tan\dfrac{\theta}{2}$ | $\dfrac{1 - \cos\theta}{\sin\theta} = \dfrac{\sin\theta}{1 + \cos\theta}$ |

## Product to sum

| Product | Sum |
|---|---|
| $\sin\alpha\cos\beta$ | $\tfrac12[\sin(\alpha + \beta) + \sin(\alpha - \beta)]$ |
| $\cos\alpha\sin\beta$ | $\tfrac12[\sin(\alpha + \beta) - \sin(\alpha - \beta)]$ |
| $\cos\alpha\cos\beta$ | $\tfrac12[\cos(\alpha - \beta) + \cos(\alpha + \beta)]$ |
| $\sin\alpha\sin\beta$ | $\tfrac12[\cos(\alpha - \beta) - \cos(\alpha + \beta)]$ |

## Sum to product

| Sum | Product |
|---|---|
| $\sin u + \sin v$ | $2\sin\dfrac{u + v}{2}\cos\dfrac{u - v}{2}$ |
| $\sin u - \sin v$ | $2\cos\dfrac{u + v}{2}\sin\dfrac{u - v}{2}$ |
| $\cos u + \cos v$ | $2\cos\dfrac{u + v}{2}\cos\dfrac{u - v}{2}$ |
| $\cos u - \cos v$ | $-2\sin\dfrac{u + v}{2}\sin\dfrac{u - v}{2}$ |

## Solving equations

| Equation | General solution |
|---|---|
| $\sin x = c$ | $x = \sin^{-1}c + 2k\pi$ or $x = \pi - \sin^{-1}c + 2k\pi$ |
| $\cos x = c$ | $x = \pm\cos^{-1}c + 2k\pi$ |
| $\tan x = c$ | $x = \tan^{-1}c + k\pi$ |

Strategy: one angle, one function, set to zero, factor, solve each factor, check (especially
after squaring).
