## Functions

| Idea | Rule |
|---|---|
| Function | each input has exactly one output (vertical line test) |
| Domain from a formula | exclude inputs that make a denominator zero or put a negative under a square root |
| Composition | $f(g(x))$: apply $g$ first |
| Zeros | solutions of $f(x) = 0$ = $x$-intercepts |
| Average rate of change | $\dfrac{f(b) - f(a)}{b - a}$ |

## Square roots

| Rule | Statement |
|---|---|
| Principal square root | $\sqrt a$ is the nonnegative number whose square is $a$ ($a \ge 0$) |
| Perfect squares | $1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, \dots$ |
| Product rule | $\sqrt{ab} = \sqrt a\,\sqrt b$ ($a, b \ge 0$) |
| Quotient rule | $\sqrt{\tfrac ab} = \tfrac{\sqrt a}{\sqrt b}$ ($a \ge 0$, $b > 0$) |
| Simplest form | no perfect-square factor (other than 1) left under the root |
| Like radicals | $m\sqrt a + n\sqrt a = (m + n)\sqrt a$; unlike radicals don't combine |
| Not a rule | $\sqrt{a + b} \ne \sqrt a + \sqrt b$ |
| Square of a root | $\sqrt{x^2} = \lvert x \rvert$ |
| Conjugates | $(a + \sqrt b)(a - \sqrt b) = a^2 - b$ |

Rational or irrational: $\sqrt n$ of a whole number is rational only when $n$ is a perfect square. Rational + irrational and nonzero rational × irrational are always irrational.
