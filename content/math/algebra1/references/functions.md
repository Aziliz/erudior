## Functions

| Idea | Rule |
|---|---|
| Function | each input has exactly one output (vertical line test) |
| Domain from a formula | exclude inputs that make a denominator zero or put a negative under a square root |
| Composition | $f(g(x))$: apply $g$ first |
| Zeros | solutions of $f(x) = 0$ = $x$-intercepts |
| Average rate of change | $\dfrac{f(b) - f(a)}{b - a}$ |
| Solving $f(x) = g(x)$ | $x$-coordinates where the graphs of $f$ and $g$ intersect |

## Transformations of $y = f(x)$

| Equation | Effect on the graph |
|---|---|
| $y = f(x) + k$ | up $k$ (down if $k < 0$) |
| $y = f(x - h)$ | right $h$ (left if $h < 0$); $f(x + 3)$ moves left 3 |
| $y = a\,f(x)$ | vertical stretch by $\lvert a \rvert$; flip over the $x$-axis if $a < 0$ |
| $y = a\,f(x - h) + k$ | point $(p, q)$ moves to $(p + h,\ aq + k)$ |

## Piecewise and step functions

| Idea | Rule |
|---|---|
| Piecewise function | each formula has a condition; conditions don't overlap; use only the piece whose condition the input meets |
| Endpoints | closed dot for $\le$, $\ge$; open dot for $<$, $>$ |
| Absolute value | $\lvert x \rvert = x$ for $x \ge 0$, $-x$ for $x < 0$; $\lvert ax + b \rvert$ splits where $ax + b = 0$ |
| Greatest integer | $\lfloor x \rfloor$ = greatest integer $\le x$: $\lfloor 3.7 \rfloor = 3$, $\lfloor -1.2 \rfloor = -2$ |
| "Per hour or part of an hour" | rounds up: steps closed on the right |

## Square roots

| Rule | Statement |
|---|---|
| Principal square root | $\sqrt a$ is the nonnegative number whose square is $a$ ($a \ge 0$) |
| Perfect squares | $1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, \dots$ |
| Product rule | $\sqrt{ab} = \sqrt a\,\sqrt b$ ($a, b \ge 0$) |
| Quotient rule | $\sqrt{\tfrac ab} = \tfrac{\sqrt a}{\sqrt b}$ ($a \ge 0$, $b > 0$) |
| Simplest form | no perfect-square factor (other than 1) left under the root |
| Like radicals | $m\sqrt a + n\sqrt a = (m + n)\sqrt a$; unlike radicals don't combine |
| Not a rule | $\sqrt{a + b} \ne \sqrt a + \sqrt b$ |
| Square of a root | $\sqrt{x^2} = \lvert x \rvert$ |
| Conjugates | $(a + \sqrt b)(a - \sqrt b) = a^2 - b$ |

Rational or irrational: $\sqrt n$ of a whole number is rational only when $n$ is a perfect square. Rational + irrational and nonzero rational × irrational are always irrational.

## Square root and cube root functions

| | $y = a\sqrt{x - h} + k$ | $y = a\sqrt[3]{x - h} + k$ |
|---|---|---|
| Key point | starting point $(h, k)$ | center $(h, k)$ |
| Domain | $x \ge h$ | all reals |
| Range | $y \ge k$ if $a > 0$; $y \le k$ if $a < 0$ | all reals |
| Parent points | $(0, 0), (1, 1), (4, 2), (9, 3)$ | $(\pm 1, \pm 1), (\pm 8, \pm 2), (0, 0)$ |

Cube roots of negative numbers are negative: $\sqrt[3]{-27} = -3$.
