## How to form it

Perfect = present tense of *haben* or *sein* (position 2) + past participle (end of the
sentence).

| | with haben | with sein |
|---|---|---|
| ich | habe … gemacht | bin … gefahren |
| du | hast … gemacht | bist … gefahren |
| er/sie/es | hat … gemacht | ist … gefahren |
| wir | haben … gemacht | sind … gefahren |
| ihr | habt … gemacht | seid … gefahren |
| sie/Sie | haben … gemacht | sind … gefahren |

- Statement: *Ich habe gestern Fußball gespielt.*
- Time phrase first: *Gestern habe ich Fußball gespielt.*
- Yes/no question: *Hast du gestern Fußball gespielt?*
- W-question: *Wann bist du nach Hause gekommen?*
- Modal verbs are not used in the perfect at A1; their past forms (*ich konnte, ich musste*) come at A2.

## haben or sein?

| use sein | examples |
|---|---|
| movement from one place to another | *gehen, kommen, fahren, fliegen, laufen, reisen, wandern, schwimmen* |
| a change of state | *aufstehen, werden, aufwachen, einschlafen* |
| three special verbs | *sein, bleiben, passieren* |

Everything else uses *haben*, including every verb with an accusative object (*einen Film
sehen*, *ein Buch kaufen*). *Fahren* with an object takes *haben*: *Ich habe das Auto
gefahren.*

## Participle patterns

| pattern | rule | examples |
|---|---|---|
| weak (regular) | ge- + stem + -t | machen → gemacht, kaufen → gekauft, hören → gehört |
| stem ends in -t/-d | ge- + stem + -et | arbeiten → gearbeitet, warten → gewartet, antworten → geantwortet |
| strong (irregular) | ge- + stem + -en, vowel often changes | sehen → gesehen, trinken → getrunken, schreiben → geschrieben |
| mixed | ge- + changed stem + -t | bringen → gebracht, denken → gedacht, kennen → gekannt, wissen → gewusst |
| separable | prefix + ge + participle | einkaufen → eingekauft, anrufen → angerufen, aufstehen → aufgestanden |
| -ieren | no ge-, ends in -t | studieren → studiert, fotografieren → fotografiert |
| inseparable prefix (be-, ver-, er-, ent-, ge-) | no ge- | besuchen → besucht, verstehen → verstanden, erzählen → erzählt |

## war and hatte

With *sein* and *haben* the simple past is more common than the perfect.

| | sein | haben |
|---|---|---|
| ich | war | hatte |
| du | warst | hattest |
| er/sie/es | war | hatte |
| wir | waren | hatten |
| ihr | wart | hattet |
| sie/Sie | waren | hatten |
