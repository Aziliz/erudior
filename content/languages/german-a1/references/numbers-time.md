## Numbers 0–20

| | | | |
|---|---|---|---|
| 0 *null* | 6 *sechs* | 11 *elf* | 16 *sechzehn* |
| 1 *eins* | 7 *sieben* | 12 *zwölf* | 17 *siebzehn* |
| 2 *zwei* (*zwo*) | 8 *acht* | 13 *dreizehn* | 18 *achtzehn* |
| 3 *drei* | 9 *neun* | 14 *vierzehn* | 19 *neunzehn* |
| 4 *vier* | 10 *zehn* | 15 *fünfzehn* | 20 *zwanzig* |
| 5 *fünf* | | | |

13–19 are the unit + *zehn*. Two lose letters: *sechzehn* (not sechszehn), *siebzehn* (not siebenzehn). *zwo* is used on the phone and in announcements so it isn't confused with *drei*.

## Tens and 21–99

| | | |
|---|---|---|
| 10 *zehn* | 40 *vierzig* | 70 *siebzig* |
| 20 *zwanzig* | 50 *fünfzig* | 80 *achtzig* |
| 30 *dreißig* | 60 *sechzig* | 90 *neunzig* |

Tens end in *-zig*, except *dreißig* (with *ß*). From 21 to 99 the unit comes first, joined by *und*, all in one word:

| Number | German | Literally |
|---|---|---|
| 21 | *einundzwanzig* | one-and-twenty |
| 34 | *vierunddreißig* | four-and-thirty |
| 57 | *siebenundfünfzig* | seven-and-fifty |
| 66 | *sechsundsechzig* | six-and-sixty |
| 99 | *neunundneunzig* | nine-and-ninety |

*eins* becomes *ein-* before *und*: *einundzwanzig*. *sechs* and *sieben* keep their full form before *und* (*sechsundsechzig, siebenundsiebzig*) but shorten in *sechzig* and *siebzig*.

## Hundreds, thousands, a million

| Number | German |
|---|---|
| 100 | *hundert* / *einhundert* |
| 101 | *hunderteins* |
| 115 | *hundertfünfzehn* |
| 199 | *hundertneunundneunzig* |
| 200 | *zweihundert* |
| 486 | *vierhundertsechsundachtzig* |
| 1.000 | *tausend* / *eintausend* |
| 1.001 | *tausendeins* |
| 2.750 | *zweitausendsiebenhundertfünfzig* |
| 10.000 | *zehntausend* |
| 65.000 | *fünfundsechzigtausend* |
| 100.000 | *hunderttausend* |
| 1.000.000 | *eine Million* |
| 2.500.000 | *zwei Komma fünf Millionen* / *zweieinhalb Millionen* |

Pattern: thousands + hundreds + (units *und* tens). Everything below a million is written as one word. *die Million* is a noun: *eine Million, zwei Millionen*.

## Writing numbers

| German | English | Meaning |
|---|---|---|
| *1.000* or *1 000* | 1,000 | one thousand |
| *2,5* | 2.5 | two point five, said *zwei Komma fünf* |
| *0,75 l* | 0.75 l | three quarters of a litre |

A point (or a space) groups thousands; a comma marks decimals.

## Prices

| Written | Said |
|---|---|
| *1,00 €* | *ein Euro* |
| *2,50 €* | *zwei Euro fünfzig* |
| *9,99 €* | *neun Euro neunundneunzig* |
| *0,60 €* | *sechzig Cent* |
| *15,05 €* | *fünfzehn Euro fünf* |
| *1.200,00 €* | *tausendzweihundert Euro* or *zwölfhundert Euro* |

- No plural after a number: *zehn Euro, fünfzig Cent*.
- No *und* and no *Cent* in the middle: *zwei Euro fünfzig*.
- Questions: *Was kostet …? / Wie viel kostet …?* (one thing), *Was kosten …?* (several). The total: *Das macht 12,40 €.*
- Quantities have no "of": *ein Kilo Äpfel, 200 Gramm Käse, ein Liter Milch, eine Flasche Wasser*. *Kilo, Gramm, Liter, Stück* stay singular after numbers (*zwei Kilo*); *Flasche, Packung* take the plural (*zwei Flaschen*).

## Ordinal numbers and dates

| | | | |
|---|---|---|---|
| 1. *erste* | 6. *sechste* | 11. *elfte* | 20. *zwanzigste* |
| 2. *zweite* | 7. *siebte* | 12. *zwölfte* | 21. *einundzwanzigste* |
| 3. *dritte* | 8. *achte* | 13. *dreizehnte* | 30. *dreißigste* |
| 4. *vierte* | 9. *neunte* | 16. *sechzehnte* | 31. *einunddreißigste* |
| 5. *fünfte* | 10. *zehnte* | 19. *neunzehnte* | 100. *hundertste* |

- 1–19: number + *-te*. Irregular: *erste, dritte, siebte, achte* (*achte* has only one *t*).
- From 20: number + *-ste*.
- In writing, an ordinal is a number with a point: *der 3. Mai* = *der dritte Mai*.

| Use | Pattern | Example |
|---|---|---|
| What's the date? | *der* + ordinal + *-e* | *Heute ist der 1. Juli.* (*der erste Juli*) |
| On which day? | *am* + ordinal + *-en* | *am 1. Juli* (*am ersten Juli*) |
| Written date | day. month. year | *01.07.2026* or *1. Juli 2026* |

Questions: *Welches Datum ist heute?* / *Der Wievielte ist heute?* — What's the date today? *Wann hast du Geburtstag? — Am 12. März.*

Years are read in hundreds up to 1999, and as thousands from 2000:

| Year | Said |
|---|---|
| 1989 | *neunzehnhundertneunundachtzig* |
| 2000 | *zweitausend* |
| 2026 | *zweitausendsechsundzwanzig* |

Say *2026* or *im Jahr 2026*, never *in 2026*.

## Clock time

Questions: *Wie spät ist es?* / *Wie viel Uhr ist es?* Answer: *Es ist …*. At what time? *Um wie viel Uhr …? / Wann …? — Um …*

### Official (24-hour)

Hours + *Uhr* + minutes. Used for timetables, opening hours, appointments, radio and TV.

| Written | Said |
|---|---|
| 6:00 | *sechs Uhr* |
| 9:10 | *neun Uhr zehn* |
| 13:30 | *dreizehn Uhr dreißig* |
| 17:45 | *siebzehn Uhr fünfundvierzig* |
| 0:05 | *null Uhr fünf* |

### Informal (12-hour)

| Time | Said | Note |
|---|---|---|
| 8:00 | *acht (Uhr)* | |
| 8:05 | *fünf nach acht* | *nach* = past |
| 8:15 | *Viertel nach acht* | regional: *viertel neun* |
| 8:20 | *zwanzig nach acht* | also *zehn vor halb neun* |
| 8:25 | *fünf vor halb neun* | |
| 8:30 | *halb neun* | half way to nine |
| 8:35 | *fünf nach halb neun* | |
| 8:40 | *zwanzig vor neun* | also *zehn nach halb neun* |
| 8:45 | *Viertel vor neun* | regional: *drei viertel neun* |
| 8:55 | *fünf vor neun* | *vor* = to |
| 1:00 | *ein Uhr* / *eins* | never *eins Uhr* |
| 12:00 | *zwölf Uhr* | *Mittag* (noon), *Mitternacht* (midnight) |

*halb* always points to the next hour: *halb drei* = 2:30. Add *morgens, nachmittags, abends* if needed: *um acht Uhr abends* (8 p.m.).

*die Uhr* = o'clock (no plural in times); *die Stunde* = an hour of time: *Es ist zwei Uhr* vs *Ich warte zwei Stunden*.

## Days of the week

All masculine: *der Montag*.

| German | Short | English |
|---|---|---|
| *Montag* | Mo | Monday |
| *Dienstag* | Di | Tuesday |
| *Mittwoch* | Mi | Wednesday |
| *Donnerstag* | Do | Thursday |
| *Freitag* | Fr | Friday |
| *Samstag* (north also *Sonnabend*) | Sa | Saturday |
| *Sonntag* | So | Sunday |

*das Wochenende* = Saturday and Sunday. With *-s* and a small letter a day means "every": *montags* = on Mondays.

## Parts of the day

| German | Roughly | "in the …" | "every …" |
|---|---|---|---|
| *der Morgen* | 5–9 | *am Morgen* | *morgens* |
| *der Vormittag* | 9–12 | *am Vormittag* | *vormittags* |
| *der Mittag* | 12–14 | *am Mittag* | *mittags* |
| *der Nachmittag* | 14–18 | *am Nachmittag* | *nachmittags* |
| *der Abend* | 18–23 | *am Abend* | *abends* |
| *die Nacht* | 23–5 | *in der Nacht* | *nachts* |

| Today | Yesterday | Tomorrow |
|---|---|---|
| *heute Morgen* | *gestern Morgen* | *morgen früh* |
| *heute Nachmittag* | *gestern Nachmittag* | *morgen Nachmittag* |
| *heute Abend* | *gestern Abend* | *morgen Abend* |

*morgen* (small) = tomorrow; *der Morgen* (capital) = the morning. Tomorrow morning is *morgen früh*.

## Months and seasons

All masculine: *der Januar*, *der Sommer*.

| | | | |
|---|---|---|---|
| *Januar* (Austria: *Jänner*) | *April* | *Juli* | *Oktober* |
| *Februar* | *Mai* | *August* | *November* |
| *März* | *Juni* | *September* | *Dezember* |

| Season | German |
|---|---|
| spring | *der Frühling* |
| summer | *der Sommer* |
| autumn, fall | *der Herbst* |
| winter | *der Winter* |

On the phone people sometimes say *Juno* and *Julei* to keep *Juni* and *Juli* apart.

## Time prepositions

| Preposition | With | Examples |
|---|---|---|
| *um* | clock times | *um 8 Uhr, um halb drei* |
| *am* | days, dates, parts of the day, the weekend | *am Montag, am 3. Mai, am Abend, am Wochenende* |
| *in der* | the night | *in der Nacht* |
| *im* | months, seasons | *im Mai, im Sommer* |
| *von … bis* | a period from start to end | *von 9 bis 17 Uhr, von Montag bis Freitag* |
| *bis* | an end point | *bis morgen, bis acht Uhr* |
| no preposition | years | *2026* or *im Jahr 2026* |

Question words: *Wann?* (when?), *Um wie viel Uhr?* (at what time?), *Wie lange?* (how long?), *Wie oft?* (how often?).

How often: *immer* (always) – *oft* (often) – *manchmal* (sometimes) – *nie* (never).
