# German A1: research notes (2026-10-17)

## Scope
- CEFR A1 global scale: everyday expressions, introducing yourself, simple personal questions, simple interaction with a helpful partner. https://www.coe.int/en/web/common-european-framework-reference-languages/table-1-cefr-3.3-common-reference-levels-global-scale
- Goethe-Zertifikat A1: Start Deutsch 1 aims and task description: https://goethe.de/pro/relaunch/prf/et/Pruefungsziele_Testbeschreibung_A1_SD1.pdf ; overview https://www.goethe.de/ins/si/de/spr/prf/gzsd1.html
- Goethe A1 word list (about 650 entries; all to be understood, about half active), topic areas plus fixed groups (numbers, time, weekdays, months, seasons, currency, measures, countries, colours, directions): https://www.goethe.de/pro/relaunch/prf/de/A1_SD1_Wortliste_02.pdf . Copyrighted: used only for the size target and topic coverage, not copied.
- Grammar scope cross-checked with Bard College Berlin's A1 curriculum (Netzwerk neu A1) and MiraCosta College German 101.

## Exam format (Start Deutsch 1)
Hören ~20 min (3 parts), Lesen ~25 min (3 parts), Schreiben ~20 min (form + ~30-word message), Sprechen ~15 min in a group. 100 points, pass 60. The task description shows 15 raw points per part in places and 25 in the summary table; the course only states the 100/60 totals.
