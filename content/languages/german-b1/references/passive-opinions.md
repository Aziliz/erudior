## The passive in every tense

The passive is built with *werden* + Partizip II. The accusative object of the active sentence becomes the subject, and the verb agrees with it.

| tense | form | example |
|---|---|---|
| present | *wird / werden* + participle | *Das Glas wird gesammelt. Die Dosen werden sortiert.* |
| Präteritum | *wurde / wurden* + participle | *Die Brücke wurde 1950 gebaut.* |
| Perfekt | *ist / sind* + participle + *worden* | *Mein Fahrrad ist gestohlen worden.* |
| Plusquamperfekt *(receptive)* | *war / waren* + participle + *worden* | *Die Bewohner waren schon gerettet worden.* |
| with a modal (present) | modal + participle + *werden* | *Der Antrag muss eingereicht werden.* |
| with a modal (past) | *musste / konnte / durfte* + participle + *werden* | *Die Straße musste gesperrt werden.* |

## Forms of werden

| | present | Präteritum | Perfekt (passive) |
|---|---|---|---|
| *ich* | *werde* | *wurde* | *bin … worden* |
| *du* | *wirst* | *wurdest* | *bist … worden* |
| *er / sie / es* | *wird* | *wurde* | *ist … worden* |
| *wir* | *werden* | *wurden* | *sind … worden* |
| *ihr* | *werdet* | *wurdet* | *seid … worden* |
| *sie / Sie* | *werden* | *wurden* | *sind … worden* |

*worden* in the passive; *geworden* only for *werden* = "become": *Sie ist Ärztin geworden.*

## Word order

| clause | example | end of the clause |
|---|---|---|
| main, present | *Der Müll wird dienstags abgeholt.* | participle |
| main, Perfekt | *Das Bild ist gestohlen worden.* | participle + *worden* |
| main, modal | *Der Ausweis muss vorgelegt werden.* | participle + *werden* |
| subordinate, present | *…, dass der Müll abgeholt wird.* | participle + *wird* |
| subordinate, Präteritum | *…, weil die Brücke repariert wurde.* | participle + *wurde* |
| subordinate, Perfekt | *…, dass das Bild gestohlen worden ist.* | participle + *worden* + *ist* |
| subordinate, modal | *…, dass der Antrag eingereicht werden muss.* | participle + *werden* + modal |

## Active and passive side by side

| active | passive |
|---|---|
| *Die Stadt sammelt den Biomüll.* | *Der Biomüll wird (von der Stadt) gesammelt.* |
| *Man baute die Brücke 1950.* | *Die Brücke wurde 1950 gebaut.* |
| *Jemand hat mein Rad gestohlen.* | *Mein Rad ist gestohlen worden.* |
| *Man muss den Antrag einreichen.* | *Der Antrag muss eingereicht werden.* |

## The agent: von or durch

| preposition | case | use | example |
|---|---|---|---|
| *von* | dative | the person or organisation that acts | *Der Brand wurde von einem Nachbarn bemerkt.* |
| *durch* | accusative | the means, cause or process | *Das Haus wurde durch das Feuer zerstört.* |

Most passive sentences have no agent at all.

## Alternatives to the passive

| alternative | meaning | example | = passive |
|---|---|---|---|
| *man* + active verb | one, people, you | *Man trennt den Müll.* | *Der Müll wird getrennt.* |
| *sein + zu* + infinitive *(receptive)* | must / can be done | *Der Antrag ist bis Freitag einzureichen.* | *… muss eingereicht werden.* |
| | | *Das ist leicht zu lösen.* | *… kann leicht gelöst werden.* |
| *-bar* adjective *(receptive)* | can be done | *Das ist machbar. Wir sind telefonisch erreichbar.* | *… kann gemacht / erreicht werden.* |

## Action or state

| form | meaning | example |
|---|---|---|
| *wird / wurde* + participle | the action | *Die Straße wurde um 8 Uhr gesperrt.* |
| *ist / war* + participle (state passive) | the resulting state | *Die Straße ist gesperrt.* |
| *ist* + participle + *worden* | the action, Perfekt | *Die Straße ist gesperrt worden.* |

Impersonal passive *(receptive)*: *Hier wird nicht geraucht. Es wurde bis drei Uhr gefeiert.*

## werden: three jobs

| werden + … | meaning | example |
|---|---|---|
| adjective / noun | become | *Es wird kalt. Er wird Lehrer.* |
| infinitive | future | *Es wird regnen.* |
| Partizip II | passive | *Das Haus wird gebaut.* |

## da- and wo- compounds

| preposition | da- | wo- |
|---|---|---|
| *an* | *daran* | *woran* |
| *auf* | *darauf* | *worauf* |
| *aus* | *daraus* | *woraus* |
| *bei* | *dabei* | *wobei* |
| *durch* | *dadurch* | *wodurch* |
| *für* | *dafür* | *wofür* |
| *gegen* | *dagegen* | *wogegen* |
| *in* | *darin* | *worin* |
| *mit* | *damit* | *womit* |
| *nach* | *danach* | *wonach* |
| *über* | *darüber* | *worüber* |
| *um* | *darum* | *worum* |
| *unter* | *darunter* | *worunter* |
| *von* | *davon* | *wovon* |
| *vor* | *davor* | *wovor* |
| *zu* | *dazu* | *wozu* |

*r* is added before a vowel. No *da-/wo-* forms with *ohne, seit, außer* or the genitive prepositions.

| about a thing | about a person |
|---|---|
| *Worauf wartest du? — Ich warte darauf.* | *Auf wen wartest du? — Ich warte auf ihn.* |
| *Womit fährst du? — Damit.* | *Mit wem fährst du? — Mit ihr.* |

### Pointing ahead to a clause

| pattern | example |
|---|---|
| da-word + *dass* | *Ich freue mich darauf, dass du kommst.* |
| da-word + *zu* | *Ich freue mich darauf, dich zu sehen.* |
| da-word + *ob* / W-word | *Es kommt darauf an, ob es regnet. Es hängt davon ab, wie viel es kostet.* |
| fixed expressions | *Es geht darum, dass … / Ich bin dafür, dass … / Ich bin dagegen, dass … / Das liegt daran, dass … / Ich bin davon überzeugt, dass …* |

## Opinions and discussion

| function | phrases |
|---|---|
| giving an opinion | *Meiner Meinung nach / Meiner Ansicht nach ist …* (verb next) · *Ich bin der Meinung / der Ansicht, dass …* · *Aus meiner Sicht …* · *Ich halte das für (richtig / übertrieben).* · *Ich finde / glaube / denke, dass …* · *Ich bin davon überzeugt, dass …* |
| asking for an opinion | *Was hältst du davon?* · *Wie siehst du das?* · *Was meinst du dazu?* · *Bist du dafür oder dagegen?* |
| agreeing | *Da stimme ich dir zu.* · *Das sehe ich genauso.* · *Da bin ich ganz deiner Meinung.* · *Da hast du recht.* · *Genau!* · *Damit bin ich einverstanden.* |
| partly agreeing | *Da hast du zwar recht, aber …* · *Im Prinzip ja, aber …* · *Das stimmt teilweise.* · *Einerseits …, andererseits …* |
| disagreeing | *Das sehe ich anders.* · *Da bin ich anderer Meinung.* · *Da muss ich dir widersprechen.* · *Ich habe da meine Zweifel.* · *Das halte ich für übertrieben.* · *Das stimmt so nicht.* |
| giving reasons | *Ein wichtiges Argument dafür / dagegen ist …* · *Das liegt daran, dass …* · *Zum Beispiel …* · *Ich habe selbst erlebt, dass …* |
| it depends | *Es kommt darauf an.* · *Es kommt darauf an, ob / wie …* · *Es hängt davon ab, ob …* |
| managing the discussion | *Darf ich kurz etwas dazu sagen?* · *Lass mich bitte ausreden.* · *Was meinst du damit?* · *Kannst du ein Beispiel dafür nennen?* · *Ich wollte noch etwas ergänzen.* |
| concluding | *Wir sind uns also einig, dass …* · *Wir haben einen Kompromiss gefunden.* · *Zusammenfassend kann man sagen, dass …* |

Cases to remember: *halten für* + Akk · *zustimmen* + Dat · *widersprechen* + Dat · *einverstanden mit* + Dat.
