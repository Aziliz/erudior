## Simple past endings

Every verb uses the same endings after its past stem. The *ich* and *er/sie/es* forms have no ending.

| | weak: sagen | weak in -t/-d: arbeiten | strong: finden | mixed: denken |
|---|---|---|---|---|
| ich | sagte | arbeitete | fand | dachte |
| du | sagtest | arbeitetest | fandest | dachtest |
| er / sie / es | sagte | arbeitete | fand | dachte |
| wir | sagten | arbeiteten | fanden | dachten |
| ihr | sagtet | arbeitetet | fandet | dachtet |
| sie / Sie | sagten | arbeiteten | fanden | dachten |

- **Weak**: stem + *-te* (*machte, entdeckte, studierte*); *-ete* after *-t, -d* and some clusters (*berichtete, gründete, öffnete*).
- **Strong**: new vowel, no *-te* (*ging, schrieb, fuhr*). Stems in *-d/-t* add *-e-* before *-st* and *-t*: *du fandest, ihr fandet*.
- **Mixed**: new vowel + *-te* (*brachte, kannte, wusste*).
- **Separable** verbs split in a main clause: *Sie stand früh auf.* In a subordinate clause: *…, als sie früh aufstand.*

## Plusquamperfekt (past perfect)

*hatte* or *war* (whichever the verb uses in the perfect) + past participle.

| | with haben | with sein |
|---|---|---|
| ich | hatte … gemacht | war … gegangen |
| du | hattest … gemacht | warst … gegangen |
| er / sie / es | hatte … gemacht | war … gegangen |
| wir | hatten … gemacht | waren … gegangen |
| ihr | hattet … gemacht | wart … gegangen |
| sie / Sie | hatten … gemacht | waren … gegangen |

| conjunction | its clause | main clause | example |
|---|---|---|---|
| *nachdem* | past perfect | simple past / perfect | *Nachdem sie gegessen hatte, ging sie.* |
| *nachdem* | perfect | present / future | *Nachdem ich gegessen habe, gehe ich.* |
| *bevor* | same tense as main clause | | *Bevor sie ging, aß sie.* |

## Futur I (future)

*werden* in position 2 + infinitive at the end.

| | werden | example |
|---|---|---|
| ich | werde | *Ich werde dir helfen.* |
| du | wirst | *Du wirst es schaffen.* |
| er / sie / es | wird | *Es wird regnen.* |
| wir | werden | *Wir werden sehen.* |
| ihr | werdet | *Ihr werdet staunen.* |
| sie / Sie | werden | *Sie werden morgen ankommen.* |

With a modal: *Wir werden sparen müssen.* In a subordinate clause: *…, dass es regnen wird.*

| werden + … | meaning | example |
|---|---|---|
| noun / adjective | to become | *Sie wird Ärztin. Es wird kalt.* |
| infinitive | future | *Sie wird kommen.* |
| infinitive + *wohl* | guess about now | *Sie wird wohl krank sein.* |
| past participle | passive | *Das Haus wird gebaut.* |

## Which tense when?

| situation | tense | example |
|---|---|---|
| novels, news, reports, biographies | simple past | *Die Mauer fiel 1989.* |
| conversation, chats, informal e-mails | perfect (but *war, hatte*, modals in the simple past) | *Ich bin gestern ins Kino gegangen.* |
| something earlier than the story's past | past perfect | *Sie hatte das Buch schon gelesen.* |
| a plan with a time word | present | *Morgen fahre ich nach Wien.* |
| prediction, promise, intention | future | *Das wird nicht funktionieren.* |
| a guess about now | future + *wohl* | *Er wird wohl im Büro sein.* |
| something still going on since the past | present + *seit* | *Ich wohne seit 2020 hier.* |

## Adjectival nouns

| | masculine | feminine | plural |
|---|---|---|---|
| nom. with *der / ein* | der Erwachsene / ein Erwachsener | die / eine Erwachsene | die Erwachsenen / Erwachsene |
| acc. | den / einen Erwachsenen | die / eine Erwachsene | die Erwachsenen / Erwachsene |
| dat. | dem / einem Erwachsenen | der / einer Erwachsenen | den Erwachsenen / Erwachsenen |
| gen. | des / eines Erwachsenen | der / einer Erwachsenen | der Erwachsenen / Erwachsener |

Common: *der/die Angestellte, Arbeitslose, Bekannte, Deutsche, Einheimische, Erwachsene, Fremde, Jugendliche, Verwandte; der Beamte* (but *die Beamtin*).

Neuter for things and ideas: *das Gute, das Wichtigste; etwas / nichts / viel / wenig Neues; alles Gute*.
