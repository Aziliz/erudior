## lassen

Present: *ich lasse, du lässt, er/sie/es lässt, wir lassen, ihr lasst, sie/Sie lassen*. Präteritum: *ließ*.

| use | pattern | example | English |
|---|---|---|---|
| leave | *lassen* + object | *Ich lasse die Tür offen.* | I leave the door open. |
| have something done | *lassen* + object + infinitive | *Ich lasse das Auto reparieren.* | I'm having the car repaired. |
| have something done to yourself | *sich* (dative) *lassen* + object + infinitive | *Ich lasse mir die Haare schneiden.* | I'm having my hair cut. |
| let, allow | *lassen* + person + infinitive | *Sie lässt ihren Sohn allein fahren.* | She lets her son go alone. |
| make (someone do) | *lassen* + person + infinitive | *Der Chef lässt uns warten.* | The boss keeps us waiting. |
| suggestion | *Lass uns / Lasst uns* + infinitive | *Lass uns gehen!* | Let's go! |
| can be done *(receptive)* | *sich lassen* + infinitive | *Das Fenster lässt sich nicht öffnen.* | The window won't open. |

| perfect | example |
|---|---|
| with another infinitive: two infinitives | *Ich habe das Auto reparieren lassen.* |
| without another infinitive: *gelassen* | *Ich habe den Schlüssel im Auto gelassen.* |

*lassen* takes a bare infinitive, never *zu*.

## Reported speech

| original | report | rule |
|---|---|---|
| „Ich bin krank." | *Er sagt, dass er krank ist.* / *Er sagt, er ist krank.* | statement: *dass* + verb at the end, or a comma + normal order |
| „Haben Sie Zeit?" | *Sie fragt, ob ich Zeit habe.* | yes/no question: *ob* |
| „Wann kommst du?" | *Er fragt, wann ich komme.* | W-question: question word + verb at the end |
| „Rufen Sie mich an!" | *Sie sagt, ich soll sie anrufen.* | instruction: *sollen* |
| „Das ist kein Problem." | *Sie meinte, das wäre kein Problem.* | Konjunktiv II: distance, common in speech |

Change the pronouns to fit the new speaker. The tense can stay as it was.

### Konjunktiv I *(recognize only)*

| infinitive | er/sie/es | past |
|---|---|---|
| *sein* | *sei* (plural *seien*) | *sei gegangen* |
| *haben* | *habe* | *habe gemacht* |
| *werden* | *werde* | |
| *kommen* | *komme* | *sei gekommen* |
| *geben* | *gebe* | *habe gegeben* |
| *können* | *könne* | |
| *müssen* | *müsse* | |
| *wollen* | *wolle* | |
| *wissen* | *wisse* | *habe gewusst* |

Recognize: third person + *-e*, or *sei/seien*. Meaning: "(he/she/they) said that …". Where Konjunktiv I looks like the present (*sie haben*), news texts use Konjunktiv II (*sie hätten*). Also: *laut* + dative/genitive (according to), *angeblich* (supposedly).

## A short presentation

| part | phrases |
|---|---|
| introduction | *In meiner Präsentation geht es um …* / *Ich möchte heute über … sprechen.* / *Zuerst …, danach …, zum Schluss …* |
| own experience | *Ich habe selbst erlebt, dass …* / *Als ich in … war, …* / *Ich persönlich …* |
| your home country | *In meinem Heimatland ist das ganz anders / ähnlich.* / *Bei uns ist es üblich, dass …* |
| pros and cons | *Ein Vorteil ist, dass …* / *Ein Nachteil ist, dass …* / *Einerseits …, andererseits …* / *Erstens …, zweitens …* |
| opinion | *Meiner Meinung nach …* / *Ich bin der Meinung, dass …* / *Ich finde es wichtig, dass …* |
| conclusion | *Abschließend möchte ich sagen, dass …* / *Zusammenfassend kann man sagen: …* / *Vielen Dank fürs Zuhören.* |
| reacting to a talk | *Danke für deine Präsentation. Besonders interessant fand ich …* / *Ich habe eine Frage: …* / *Wie ist das bei dir?* |

## Letters and e-mails

| | informal | semi-formal | formal |
|---|---|---|---|
| opening | *Liebe Mia, / Lieber Tom, / Hallo Sam,* | *Liebe Frau Kraus, / Lieber Herr Ott,* | *Sehr geehrte Frau Kraus, / Sehr geehrter Herr Ott, / Sehr geehrte Damen und Herren,* |
| first line | *danke für deine Mail!* | *vielen Dank für Ihre Nachricht.* | *ich wende mich an Sie, weil …* / *ich schreibe Ihnen wegen …* |
| asking | *Hast du Lust, …? Kannst du mir sagen, …?* | *Könnten Sie mir bitte …?* | *Ich möchte mich nach … erkundigen.* / *Könnten Sie mir bitte mitteilen, ob …?* |
| complaining | *Ich habe mich echt über … geärgert.* | *Leider gibt es ein Problem mit …* | *Leider muss ich mich über … beschweren.* / *Leider war … beschädigt / mangelhaft.* / *Ich bitte Sie um Ersatz bzw. um die Rückzahlung des Kaufpreises.* |
| apologizing | *Sorry, dass …* / *Tut mir leid, dass …* | *Es tut mir sehr leid, dass …* / *Entschuldigen Sie bitte, dass …* | *Ich bedauere sehr, dass …* / *Bitte entschuldigen Sie die Unannehmlichkeiten.* |
| closing line | *Schreib mir bald!* | *Vielen Dank im Voraus.* | *Ich freue mich auf Ihre Antwort.* / *Für Rückfragen stehe ich gern zur Verfügung.* |
| closing | *Viele Grüße / Liebe Grüße / Bis bald* | *Viele Grüße / Freundliche Grüße* | *Mit freundlichen Grüßen* |

- Comma after the opening; the next line starts with a small letter.
- No punctuation after the closing.
- *Sie, Ihnen, Ihr* always with a capital; *du, dich, dein* small or capital.
- A formal letter: *Absender*, *Empfänger*, place and date, *Betreff*, opening, paragraphs, closing, name.
