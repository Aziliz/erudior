# Language proficiency course tracks

Roadmap date: 2026-10-28. Courses are free to learn. These are **independent Erudior preparation courses**, not official exam-provider certifications or guaranteed equivalencies.

## Shared instructional contract

Each level is its own course with exam-level objectives, prerequisite and placement checks, progressive grammar and vocabulary, listening, reading, typed writing, pronunciation and recorded speaking practice, conversation dialogues, cultural context, adaptive quizzes, mock timed exams and a completion review. Separate **exam-readiness** from broader four-skill **communicative competence**. Retain sources and the revision date for every exam blueprint; do not claim exam affiliation. Validate language-specific fonts, bidirectional/transliteration where required, IME keyboard support and speech processing availability. Use authentic examples written or licensed for Erudior, not copied exam question banks.

## Special language decisions

* “Indian” names a country, not one language. Hindi is a placeholder pending selection; other languages (Tamil, Telugu, Bengali, Urdu, Punjabi, etc.) may be separate tracks.
* Portuguese should offer Portugal-focused CAPLE and Brazil-focused usage from early levels; consider a separate Celpe-Bras readiness track if requested.
* Chinese should specify **Mandarin, simplified characters** as the default HSK-aligned track, with traditional-character literacy optional.
* Japanese is included because JLPT N5–N1 was explicitly cited as the requested competency-test model.
* Do not auto-label proficiency courses as school-grade credits or official professional certifications; distinguish independent preparation from authorized examination.

## Additional global languages (2026-10-28)

These 14 additional language tracks are proposed independent Erudior courses, not official certification programs. The course names below reflect **curriculum levels**, which may differ from externally marketed exam products.

| Language | Framework and pathway | Important distinctions |
|---|---|---|
| Arabic | Modern Standard Arabic, CEFR A1–C2 | CEFR-aligned Erudior levels, not a single universal Arabic certificate. Add Egyptian and Levantine spoken-dialect pathways later. |
| Bengali | ACTFL Novice–Distinguished | Broad ACTFL bands; language-specific exam-provider alignment must be verified before claiming a test-prep pathway. Bengali script required. |
| Indonesian | UKBI with CEFR A1–C2 curriculum crosswalk | UKBI score bands are not officially identical to CEFR A1–C2; publish a documented crosswalk before calling courses UKBI preparation. |
| Urdu | ACTFL Novice–Distinguished | Nastaliq script, register differences and Hindi cognate reuse require independent assessment. |
| Korean | TOPIK levels 1–6 | TOPIK I covers 1–2, TOPIK II covers 3–6. Include spoken and production skills beyond exam scope as appropriate. |
| Turkish | TYS with CEFR A1–C2 learning progression | TYS does not necessarily issue certificates at every CEFR level; independently verify currently awarded levels before claiming a level-specific certificate. |
| Vietnamese | Vietnamese six-level proficiency framework Levels 1–6 | Standard levels should be mapped to the relevant Vietnamese-language proficiency examination; northern/southern variation supported. |
| Punjabi | ACTFL Novice–Distinguished | Provide Gurmukhi and Shahmukhi script pathways. |
| Tamil | ACTFL Novice–Distinguished | Tamil script, formal/written vs spoken registers; no implied ACTFL certification. |
| Persian (Farsi) | SAMFA and CEFR-aligned A1–C2 progression | Confirm official SAMFA versions/score mappings separately; Iranian Persian default. |
| Swahili | CEFR-aligned A1–C2 curriculum | No single universal exam inferred; provide standard Kiswahili and regional usage. |
| Filipino (Tagalog) | ACTFL Novice–Distinguished | Teach Filipino/Tagalog usage and confirm assessment availability by test type. |
| Telugu | ACTFL Novice–Distinguished | Telugu script and pronunciation, no implied dedicated nationally administered exam. |
| Marathi | ACTFL Novice–Distinguished | Devanagari-script literacy and spoken-language skills. |

**Implementation rule:** Each named level is an independently completable course. Use exact published standards and versioned exam blueprints where available. Where an exam does not offer a matching level, the listed level is an Erudior instructional designation, **not** an official certificate or guaranteed equivalence. ACTFL proficiency bands can have sublevels; implement granular assessment objectives within each course. Do not reproduce copyrighted examination questions without permission.

**Script and dialect planning:** Arabic dialects, Hindi/Urdu, Punjabi scripts, Indonesian and Malaysian Malay distinctions, regional Vietnamese, and European/Brazilian Portuguese need explicit localization and skill rubrics.
